# Project Design Direction

- Use cold Swiss International Typographic Style as the default direction for editorial graphics and infographics: strict asymmetric grids, disciplined sans-serif typography, generous systematic whitespace, tabular numerals, cool white or light-gray backgrounds, near-black text, and one restrained cobalt-blue accent.
- Prefer typography, scale, alignment, rules, and data relationships over illustration or decoration.
- Avoid warm paper tones, hand-drawn marks, ornamental icons, rounded cards, gradients, shadows, and decorative clutter unless the user explicitly requests a different direction.
